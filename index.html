三使用体验与感受

三个 Agent 有共同点，也有明显区别。

① 形式不同

WorkBuddy 和 Trae 都是应用程序界面或网页端；Claude 则在终端运行，需要从终端调用。

② 模型选择不同

WorkBuddy / Trae 可选有限模型或开自动模式；Claude 则按需求从众多开放 API 中购买接入。

③ 收费不同

前两者对普通用户有积分制（签到领取、部分限免但会堵车）；Claude 收费完全取决于所购 API 的规则。

它们和"普通对话 AI"的本质区别

这些 Agent 能直接操作你的电脑完成任务；但本质上仍是通过代码 / 脚本完成，因此也会受限于本地应用的 API 是否开放——若不开放，Agent 依旧无法直接操作。

关于"审批模式"

大多数 Agent 都有审批模式选择。执行重要指令、修改重要文件时，不同模式申请权限的方式不同：开全自动，任务中 Agent 自己审批、无需人工干预，但有风险；开手动，则整个任务中你要不断做"选择题"，告诉它是否同意执行。

我的倾向：目前我还是更倾向于使用 WorkBuddy 和 Trae——原因很简单：在较少的任务量内，它们不用我掏钱。
